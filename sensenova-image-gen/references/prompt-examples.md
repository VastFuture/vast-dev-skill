## Prompt 撰写技巧

### 1. 结构化描述

✅ **好的示例**：
```
左侧区域包含三个要点：
- 要点1: 具体内容
- 要点2: 具体内容
- 要点3: 具体内容
```

❌ **不好的示例**：
```
左边写一些功能介绍
```

### 2. 具体化内容

✅ **好的示例**：
```
标题："AI 技术发展史"
副标题："从1950年代到2020年代的里程碑"
```

❌ **不好的示例**：
```
有个标题和副标题
```

### 3. 视觉细节

✅ **好的示例**：
```
采用扁平设计风格，以蓝色(#3498DB)和绿色(#2ECC71)为主色调，
使用圆角图标和现代无衬线字体。
```

❌ **不好的示例**：
```
好看的设计
```

### 4. 布局说明

✅ **好的示例**：
```
整体采用左中右三栏布局，左栏占30%，中栏40%，右栏30%。
各栏之间用垂直分割线区隔。
```

❌ **不好的示例**：
```
分成几部分
```
