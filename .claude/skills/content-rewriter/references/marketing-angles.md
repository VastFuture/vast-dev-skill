# 营销文案多角度生成

从不同角度切入,为同一产品/服务生成多个差异化的营销文案。

## 六大营销角度

### 角度1: 性能/功能角度
强调产品的核心功能和性能优势。

**适用场景**:
- 技术型产品
- 目标受众是专业用户
- 功能确实有显著优势

**文案特点**:
- 突出具体参数和指标
- 强调技术创新
- 使用对比数据

**模板**:
```
[产品]的[核心功能],[具体性能数据]
比传统方案[提升X%]/[快X倍]/[节省X%]
[技术亮点],让[使用场景]更[高效/便捷/强大]
```

**示例** (智能手机):
```
【性能角度】
旗舰级芯片,性能提升40%
8核心CPU + 独立GPU,大型游戏流畅运行
120Hz高刷屏,滑动跟手,不掉帧
5000mAh大电池 + 65W快充,20分钟充到50%

为性能控打造的真旗舰!
```

### 角度2: 价格/性价比角度
强调产品的价格优势或高性价比。

**适用场景**:
- 价格确实有竞争力
- 目标用户价格敏感
- 中低端市场定位

**文案特点**:
- 强调"值得"、"划算"
- 使用价格对比
- 突出"少花钱多办事"

**模板**:
```
只需[价格],就能获得[价值描述]
相比[竞品],[便宜X元]但[功能不减]
[具体功能],原价[X元],现在只要[Y元]
```

**示例** (智能手机):
```
【性价比角度】
旗舰配置,中端价格!

同样的芯片,别家卖4999
同样的屏幕,别家卖5499
我们只卖2999!

不是降配,是真诚
不割韭菜,只做良心好物

2999元,享受5000元旗舰的体验
这才是真正的性价比之王!
```

### 角度3: 用户体验角度
强调使用过程中的美好体验和感受。

**适用场景**:
- 产品体验确实出色
- 目标用户重视使用感受
- 情感化营销

**文案特点**:
- 描述使用场景
- 强调感受和情绪
- 使用"你"作为主语

**模板**:
```
想象一下,[使用场景]
[产品]让你[美好体验]
再也不用[痛点],只需[简单操作]
[情感收益],这就是[产品]带给你的改变
```

**示例** (智能手机):
```
【体验角度】
早上,闹钟响起,柔和的屏幕亮度不刺眼
地铁上,120Hz高刷屏,刷信息流滑顺如丝

这就是你一直想要的手机体验

- 目标用户重视他人评价

## 多角度组合策略

### 策略1: 双角度组合

**示例**: 性能 + 性价比
```

• 骁龙8 Gen 2芯片 - 旗舰标配

## 营销文案生成流程

### Step 1: 提取产品核心卖点
列出产品的所有优势:
- 功能优势
- 价格优势
- 体验优势
- 品牌/技术优势
- 用户口碑

### Step 2: 匹配目标受众
确定主要受众群体:
- 价格敏感型 → 价格角度
- 性能控 → 性能/技术角度
- 小白用户 → 体验角度
- 跟风型 → 社会认同角度
- 理想主义者 → 情感/生活方式角度

### Step 3: 选择主打角度
根据受众特点,选择1-2个主打角度。

### Step 4: 生成文案
按照选定的角度,生成文案。

### Step 5: 调整适配
根据平台和用户反馈,调整文案。

---

## 营销文案检查清单

- [ ] 是否突出了产品的核心卖点?
- [ ] 角度选择是否匹配目标受众?
- [ ] 不同版本之间是否有明显区分度?
- [ ] 是否使用了具体的数据和例证?
- [ ] 是否避免了虚假宣传和夸大其词?
- [ ] 是否有明确的行动召唤(CTA)?
