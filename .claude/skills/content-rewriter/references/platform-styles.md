# 平台风格指南

不同平台有不同的内容风格和用户习惯,改写时需要适配对应平台的特点。

## 微信公众号

### 风格特点
- **语气**: 专业权威,适度正式,但不生硬
- **结构**: 层次清晰,小标题明确,善用分段
- **节奏**: 中等节奏,每段3-5句话为宜
- **视觉**: 适当使用emoji(但不过度),善用加粗和引用格式

### 典型特征
```
✓ 标题: 实用型,包含关键词,10-20字
✓ 开头: 直接点题或提出问题,引发共鸣
✓ 正文: 观点→论据→例证,逻辑清晰
✓ 结尾: 总结要点或引导行动
✓ 称呼: "各位读者"、"大家"
```

### 改写策略
1. **结构调整**: 增加小标题,每个小标题下控制在200-300字
2. **语言风格**: 去掉过于口语化的表达,保持专业度
3. **增加元素**: 适当添加"我们认为"、"研究表明"等权威表达
4. **格式优化**: 关键观点加粗,数据用引用格式突出

### 示例对比

**原文** (通用风格):
```
AI技术发展很快,现在已经能做很多事情了,比如写文章、画图、聊天等等。
```

**微信公众号改写**:
```
近年来,人工智能技术呈现出**爆发式增长**的态势。从内容创作到视觉设计,从智能对话到数据分析,AI的应用场景正在全方位渗透我们的工作与生活。

根据相关研究,AI在以下领域已展现出成熟的应用能力:
- 内容生成: 自动化撰写新闻、报告等文本内容
- 视觉创作: 基于文本描述生成高质量图像
- 智能交互: 提供接近人类水平的对话体验
```

## 知乎

### 风格特点
- **语气**: 深度分析,逻辑严密,有理有据
- **结构**: 先抛结论,再详细论证,层层递进
- **节奏**: 可以写得很长,但要有干货
- **证据**: 喜欢引用数据、研究、案例

### 典型特征
```
✓ 开头: 先说结论,简明扼要
✓ 论证: 多角度分析,引用数据和研究
✓ 案例: 真实案例或亲身经历
✓ 对比: 喜欢正反对比、横向对比
✓ 总结: 归纳要点,提出建议
✓ 称呼: "题主"、"大家"、或直接第一人称
```

### 改写策略
1. **结构重组**: 把结论前置,先说"答案是XX,原因有三点"
2. **增加论证**: 补充数据、研究、案例来支撑观点
3. **深度挖掘**: 不只说"是什么",还要说"为什么"和"怎么办"
4. **个人视角**: 可以加入"我的经验是"、"我认为"等第一人称表达

### 示例对比

**原文** (通用风格):
```
AI技术发展很快,现在已经能做很多事情了,比如写文章、画图、聊天等等。
```

**知乎改写**:
```
**简单来说,AI技术已经进入实用化阶段,在内容生成、视觉创作、智能交互等领域具备了接近人类的能力水平。**

为什么这么说?我们可以从三个维度来看:

**1. 技术成熟度**
以GPT-4为代表的大语言模型,在文本理解和生成上已经达到了令人惊讶的水平。根据OpenAI的测试,GPT-4在多项标准化考试中的成绩已经超过90%的人类考生。

**2. 应用广度**
从我个人这两年的观察来看,AI应用已经从实验室走向了实际场景:
- 内容创作: 我身边的自媒体朋友,有70%已经在用AI辅助写作
- 视觉设计: Midjourney的付费用户超过1500万,说明市场需求是真实存在的
- 客服场景: 很多公司的智能客服已经能解决80%的常见问题

**3. 未来趋势**
更重要的是,这只是开始。随着多模态模型的发展,AI将在更多领域展现能力。
```

## 小红书

### 风格特点
- **语气**: 轻松种草,个人体验感强
- **结构**: 短平快,多用emoji和符号分隔
- **节奏**: 节奏明快,善用短句和感叹
- **视觉**: emoji密度高,排版活泼

### 典型特征
```
✓ 标题: 引发好奇或情绪,多用emoji
✓ 开头: 直击痛点或亮点,"姐妹们听我说!"
✓ 正文: 多用短句、感叹句、疑问句
✓ 清单: 喜欢用编号列表,每条都简短
✓ 结尾: 互动性强,"你们呢?评论区见!"
✓ 称呼: "姐妹"、"宝子们"、"集美们"
```

### 改写策略
1. **增加emoji**: 每2-3句话添加一个相关emoji
2. **口语化**: 大量使用"真的"、"超级"、"绝了"等口语词
3. **个人体验**: 改为第一人称,强调"我的体验"
4. **分点罗列**: 把段落改成编号清单,每条1-2句话
5. **制造互动**: 加入"你们用过吗?"、"有同款经历吗?"

### 示例对比

**原文** (通用风格):
```
AI技术发展很快,现在已经能做很多事情了,比如写文章、画图、聊天等等。
```

**小红书改写**:
```
姐妹们!我最近发现AI真的太太太好用了!🔥🔥🔥

之前还在手动码字、P图、回消息,现在全都可以交给AI啦!效率直接起飞✈️

给大家盘点一下我在用的AI功能:

✅ 写文案 - 再也不怕没灵感!输入关键词就能生成
✅ 做设计 - 描述一下想法,AI直接给你画出来
✅ 智能聊天 - 有问题随时问,比百度好用多了

真的强烈安利!谁用谁知道💯

你们有在用AI吗?评论区分享你最爱的功能!👇
```

## 抖音/B站(视频平台文案)

### 风格特点
- **语气**: 口语化极强,像在说话
- **结构**: 短小精悍,开头3秒决定去留
- **节奏**: 快节奏,信息密度高
- **互动**: 强引导,制造悬念和互动点

### 典型特征
```
✓ 开头: 悬念式、反转式、疑问式
✓ 节奏: 快速推进,不拖泥带水
✓ 语言: 大量语气词,"你知道吗"、"真的假的"
✓ 停顿: 用省略号和短句制造停顿感
✓ 结尾: 强引导,"双击关注不迷路"
```

### 改写策略
1. **开头抓眼球**: 用悬念或反转开场,"你绝对想不到..."
2. **口语化**: 大量语气词,模拟真实说话场景
3. **制造节奏**: 用短句和省略号制造停顿点
4. **设置钩子**: 每隔2-3句话就设置一个兴趣点
5. **互动引导**: 明确告诉观众"点赞"、"评论"、"关注"

### 示例对比

**原文** (通用风格):
```
AI技术发展很快,现在已经能做很多事情了,比如写文章、画图、聊天等等。
```

**抖音/B站改写**:
```
你知道AI现在有多强吗?

我跟你说...

写文章?秒秒钟的事儿。
画图?描述一下就行。
聊天?比真人还懂你。

你敢信?

我给你演示一下啊...

[演示画面]

看到没有?就是这么简单!

所以说啊,现在还不会用AI的,是真的亏大了!

赶紧点个关注,下期教你怎么用!
```

## 平台对比总结

| 平台 | 语气 | 结构 | 节奏 | 特色元素 |
|------|------|------|------|----------|
| 微信公众号 | 专业权威 | 清晰分层 | 中等 | 小标题、加粗、引用 |
| 知乎 | 深度理性 | 结论先行 | 可长 | 数据、案例、逻辑 |
| 小红书 | 轻松种草 | 短平快 | 明快 | 高密度emoji、清单 |
| 抖音/B站 | 口语强 | 快节奏 | 极快 | 悬念、停顿、互动 |

## 跨平台改写流程

当用户要求将一篇内容适配多个平台时:

1. **提取核心**: 先识别出3-5个核心要点
2. **分别改写**: 针对每个平台独立改写,不要互相套用
3. **验证差异**: 确保不同版本之间有明显的风格差异
4. **标注特色**: 明确指出每个版本针对哪个平台,有什么特点
