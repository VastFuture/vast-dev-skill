# 专有名词大小写规则

基于 [sparanoid/chinese-copywriting-guidelines](https://github.com/sparanoid/chinese-copywriting-guidelines) 整理。

## 核心原则

专有名词使用正确的大小写。大小写相关用法原属于英文书写范畴,但在中文文案中经常出现,容易出错。

## 特殊规则

### 1. 全大写缩写词
某些缩写词应该全部大写:
- API (不是 Api 或 api)
- SDK (不是 Sdk 或 sdk)
- HTML (不是 Html 或 html)
- CSS (不是 Css 或 css)
- JSON (不是 Json 或 json)
- XML (不是 Xml 或 xml)
- HTTP/HTTPS (不是 Http/Https 或 http/https)
- URL (不是 Url 或 url)
- SQL (不是 Sql 或 sql)
- AI (不是 Ai 或 ai)
- ML (不是 Ml 或 ml)
- UI/UX (不是 Ui/Ux 或 ui/ux)

### 2. 驼峰命名
某些产品使用驼峰命名:
- iPhone (不是 Iphone 或 IPhone)
- iPad (不是 Ipad 或 IPad)
- macOS (不是 MacOS 或 MACOS)
- iOS (不是 IOS 或 Ios)
- iPod (不是 Ipod 或 IPod)

### 3. 特殊格式
- Node.js (注意小写 js 和点号)
- Vue.js (注意小写 js 和点号)
- Next.js (注意小写 js 和点号)
- D3.js (注意小写 js 和点号)
- Three.js (注意小写 js 和点号)

### 4. 中文产品名称
某些产品有特定的中文命名规则,按照官方格式:
- 豆瓣FM (不是豆瓣 FM)
- 小米MIX (按官方格式)
- 哔哩哔哩 或 B站 (不混用)

## 网页中的处理方式

当网页中需要配合整体视觉风格而出现全部大写/小写的情形:
- HTML 中使用标准的大小写规范
- 通过 CSS 控制表现形式

```html
<!-- HTML 中使用正确的大小写 -->
<a href="https://github.com">GitHub</a>

<!-- CSS 控制显示效果 -->
<style>
  .uppercase { text-transform: uppercase; }
  .lowercase { text-transform: lowercase; }
</style>
```

## 检测模式

```javascript
// 常见错误模式
const commonMistakes = {
  'github': 'GitHub',
  'GITHUB': 'GitHub',
  'Github': 'GitHub',
  'javascript': 'JavaScript',
  'JAVASCRIPT': 'JavaScript',
  'Javascript': 'JavaScript',
  'nodejs': 'Node.js',
  'NODEJS': 'Node.js',
  'NodeJS': 'Node.js',
  'macos': 'macOS',
  'MACOS': 'macOS',
  'MacOS': 'macOS',
  'iphone': 'iPhone',
  'IPHONE': 'iPhone',
  'Iphone': 'iPhone',
  'chatgpt': 'ChatGPT',
  'CHATGPT': 'ChatGPT',
  'Chatgpt': 'ChatGPT'
};

// 检测函数
function checkProperNouns(text) {
  for (const [wrong, right] of Object.entries(commonMistakes)) {
    // 使用词边界匹配,避免匹配到单词的一部分
    const regex = new RegExp(`\\b${wrong}\\b`, 'g');
    if (regex.test(text)) {
      return { wrong, right, found: true };
    }
  }
  return { found: false };
}
```

## 不确定时的处理策略

如果遇到不确定的专有名词:
1. 访问官方网站查看正确写法
2. 查看官方文档中的书写方式
3. 查看 Wikipedia 等权威来源
4. 如果实在找不到,保持用户原文不变(不要猜测)
