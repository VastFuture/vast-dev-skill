# 标点符号规则详解

基于 [sparanoid/chinese-copywriting-guidelines](https://github.com/sparanoid/chinese-copywriting-guidelines) 整理。

## 规则1: 不重复使用标点符号

虽然中国大陆的标点符号用法允许重复使用标点符号,但是这么做会破坏句子的美观性。

### 正确示例
```
德国队竟然战胜了巴西队!
她竟然对你说「喵」?!
```

### 错误示例
```
德国队竟然战胜了巴西队!!
德国队竟然战胜了巴西队!!!!!!!!
她竟然对你说「喵」??!!
她竟然对你说「喵」?!?!??!!
```

### 规则
- 感叹号: 最多使用一个 `!`
- 问号: 最多使用一个 `?`
- 组合: `?!` 或 `!?` 各最多出现一次

## 规则2: 使用全角中文标点

### 正确示例
```
嗨!你知道嘛?今天前台的小妹跟我说「喵」了哎!
核磁共振成像(NMRI)是什么原理都不知道?JFGI!
```

### 错误示例
```
嗨! 你知道嘛? 今天前台的小妹跟我说 "喵" 了哎!
嗨!你知道嘛?今天前台的小妹跟我说"喵"了哎!
核磁共振成像 (NMRI) 是什么原理都不知道? JFGI!
核磁共振成像(NMRI)是什么原理都不知道?JFGI!
```

### 中文标点符号对照表

| 名称 | 全角(正确) | 半角(错误) |
|------|-----------|-----------|
| 逗号 | , | , |
| 句号 | 。 | . |
| 分号 | ; | ; |
| 冒号 | : | : |
| 问号 | ? | ? |
| 感叹号 | ! | ! |
| 顿号 | 、 | N/A |
| 引号 | 「」『』 或 ""'' | ""'' |
| 括号 | ()[]{}〈〉《》 | ()[]{}|
| 破折号 | —— | -- |
| 省略号 | …… | ... |

### 例外: 中文句子内夹有英文书籍名、报刊名

不应借用中文书名号,应以英文斜体表示。

```
推荐你阅读 *Hackers & Painters: Big Ideas from the Computer Age*,非常地有趣。
```

## 规则3: 数字使用半角字符

### 正确示例
```
这个蛋糕只卖 1000 元。
```

### 错误示例
```
这个蛋糕只卖 １０００ 元。
```

### 例外: 设计稿、宣传海报

在设计稿、宣传海报中如出现极少量数字的情形时,为方便文字对齐,是可以使用全角数字的。

## 规则4: 遇到完整的英文整句、特殊名词,其内容使用半角标点

### 正确示例
```
乔布斯那句话是怎么说的?「Stay hungry, stay foolish.」
推荐你阅读 *Hackers & Painters: Big Ideas from the Computer Age*,非常地有趣。
```

### 错误示例
```
乔布斯那句话是怎么说的?「Stay hungry,stay foolish。」
推荐你阅读《Hackers＆Painters:Big Ideas from the Computer Age》,非常的有趣。
```

### 规则说明
- 英文整句内部使用英文标点(半角)
- 英文书名使用斜体,不使用书名号
- `&` 等特殊符号保持半角

## 争议性用法: 简体中文使用直角引号

### 用法1: 直角引号(推荐)
```
「老师,『有条不紊』的『紊』是什么意思?」
```

### 用法2: 弯引号(也可接受)
```
"老师,'有条不紊'的'紊'是什么意思?"
```

### 说明
从语法角度两种都正确。直角引号在简体中文排版中更加清晰美观,但弯引号也符合规范。

## 检测模式

### 检测重复标点
```javascript
// 重复的感叹号
/!{2,}/

// 重复的问号
/\?{2,}/

// 混乱的组合
/[?!]{3,}/
```

### 检测全角/半角混用
```javascript
// 中文内容使用了半角标点(逗号、句号、问号、感叹号)
/[\u4e00-\u9fa5][,.\?!]/

// 全角数字
/[０-９]/
```

## 特殊情况处理

### 1. 省略号
中文: `……`(两个省略号)
英文: `...`(三个点)

### 2. 破折号
中文: `——`(占两个字符宽度)
英文: `--` 或 `—`(em dash)

### 3. 括号
- 如果括号内全是中文,使用全角括号: `(中文)`
- 如果括号内全是英文/数字,使用半角括号: `(English)`
- 如果括号内是英文专有名词缩写,使用半角括号: `核磁共振成像(NMRI)`

### 4. 冒号
- 中文语境使用全角冒号: `注意:这很重要`
- 英文 URL、时间等保持半角: `https://example.com`, `12:30`

### 5. 引号嵌套
外层使用双引号,内层使用单引号:
- 直角引号: 「外层『内层』外层」
- 弯引号: "外层'内层'外层"
