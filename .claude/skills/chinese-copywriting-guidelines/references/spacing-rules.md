# 空格规则详解

基于 [sparanoid/chinese-copywriting-guidelines](https://github.com/sparanoid/chinese-copywriting-guidelines) 整理。

## 核心原则

> 「有研究显示,打字的时候不喜欢在中文和英文之间加空格的人,感情路都走得很辛苦,有七成的比例会在 34 岁的时候跟自己不爱的人结婚,而其余三成的人最后只能把遗产留给自己的猫。毕竟爱情跟书写都需要适时地留白。」

## 规则1: 中英文之间需要增加空格

### 正确示例
```
在 LeanCloud 上,数据存储是围绕 `AVObject` 进行的。
```

### 错误示例
```
在LeanCloud上,数据存储是围绕`AVObject`进行的。
在 LeanCloud上,数据存储是围绕`AVObject` 进行的。
```

### 完整正确用法
```
在 LeanCloud 上,数据存储是围绕 `AVObject` 进行的。每个 `AVObject` 都包含了与 JSON 兼容的 key-value 对应的数据。数据是 schema-free 的,你不需要在每个 `AVObject` 上提前指定存在哪些键,只要直接设定对应的 key-value 即可。
```

### 例外情况
产品名词按照官方所定义的格式书写:
- 豆瓣FM (不是 豆瓣 FM)
- 小米MIX (按官方格式)

## 规则2: 中文与数字之间需要增加空格

### 正确示例
```
今天出去买菜花了 5000 元。
```

### 错误示例
```
今天出去买菜花了 5000元。
今天出去买菜花了5000元。
```

## 规则3: 数字与单位之间需要增加空格

### 正确示例
```
我家的光纤入屋宽带有 10 Gbps,SSD 一共有 20 TB
```

### 错误示例
```
我家的光纤入屋宽带有 10Gbps,SSD 一共有 20TB
```

### 例外: 度数/百分比与数字之间不需要增加空格

#### 正确示例
```
角度为 90° 的角,就是直角。
新 MacBook Pro 有 15% 的 CPU 性能提升。
```

#### 错误示例
```
角度为 90 ° 的角,就是直角。
新 MacBook Pro 有 15 % 的 CPU 性能提升。
```

## 规则4: 全角标点与其他字符之间不加空格

### 正确示例
```
刚刚买了一部 iPhone,好开心!
```

### 错误示例
```
刚刚买了一部 iPhone ,好开心!
刚刚买了一部 iPhone, 好开心!
```

## 特殊情况处理

### Inline Code 与中文之间的空格

这是一个**可选**规则,两种方式都可接受:

```markdown
使用`git commit`提交代码
使用 `git commit` 提交代码
```

不强制要求在 inline code 和中文之间加空格,但保持一致性。

### 链接之间的空格

这是一个**争议性**用法,从语法角度两种都正确:

#### 用法1 (推荐)
```
请 [提交一个 issue](#) 并分配给相关同事。
访问我们网站的最新动态,请 [点击这里](#) 进行订阅!
```

#### 用法2
```
请[提交一个 issue](#)并分配给相关同事。
访问我们网站的最新动态,请[点击这里](#)进行订阅!
```

### 代码块内不应用规则

在代码块、命令、URL 中**不要**应用空格规则:

```python
# 代码块内保持原样,不添加空格
def hello():
    print("Hello世界")  # 保持原样
```

```bash
# 命令中不添加空格
git commit -m "修复bug"
```

```
# URL 中不添加空格
https://github.com/user/repo
```

## CSS text-spacing 属性

CSS Text Module Level 4 的 `text-spacing` 和 Microsoft 的 `-ms-text-autospace` 可以实现自动为中英文之间增加空白。

但目前:
- 并未普及
- 其他应用场景(macOS、iOS、Windows 等用户界面)不存在此特性

所以请继续保持随手加空格的习惯。

## 检测模式

在代码中检测空格问题时,使用以下正则模式:

```javascript
// 中英文之间缺少空格
/[\u4e00-\u9fa5][a-zA-Z]|[a-zA-Z][\u4e00-\u9fa5]/

// 中文与数字之间缺少空格
/[\u4e00-\u9fa5]\d|\d[\u4e00-\u9fa5]/

// 数字与单位之间缺少空格 (排除度数和百分比)
/\d+(?!°|%)[A-Z]/
```

注意: 这些是简化的模式,实际检测需要更复杂的逻辑来处理例外情况。
