## 单个技能结构

每个技能目录包含一个 `SKILL.md`，遵循统一结构：

- **何时使用** — 触发场景
- **核心原则** — 5 个核心原则
- **专家洞察** — 来自产品领袖的引用和应用建议
- **常见错误** — 避坑指南
- **关键战术** — 可执行的战术表格
- **相关技能** — 互联的技能链接（wikilink）

## 使用方法

### Claude Code / Claude Desktop

将单个技能目录复制到 `~/.claude/skills/` 即可自动加载：

```bash
# 示例：安装"问题定义"技能
cp -r vast-lenny-pm-skills/01-问题定义-problem-definition ~/.claude/skills/
```

或按需挑选部分技能，避免本地加载过多内容。

### Obsidian

可直接作为 Obsidian vault 使用，原生支持 wikilink 互联。
