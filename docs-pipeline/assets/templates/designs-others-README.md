# Designs Others - 其他设计现状

本目录存放除 API 和数据库之外的其他设计现状。

## 目录结构

```
others/
├── README.md           # 本文件
├── businessrule.md     # 业务规则现状
└── data-dict.md        # 数据字典现状
```

## 同步检查规则

### 业务规则

| 变更类型 | 操作 |
|----------|------|
| 新增规则 | 在 `businessrule.md` 中添加规则定义 |
| 修改规则 | 更新规则定义，添加变更说明 |
| 删除规则 | 从文档中移除，记录在变更历史 |

### 数据字典

| 变更类型 | 操作 |
|----------|------|
| 新增字典 | 在 `data-dict.md` 中添加字典定义 |
| 修改字典 | 更新字典定义，添加变更说明 |
| 删除字典 | 从文档中移除，记录在变更历史 |

---

## 文档格式

### 业务规则

```markdown
## 规则名称

**规则编码**：`RULE_CODE`

**触发条件**：
- 条件1
- 条件2

**处理逻辑**：
1. 步骤1
2. 步骤2

**异常处理**：
- 异常情况1 → 处理方式1
- 异常情况2 → 处理方式2

**相关代码**：
- `com.example.xxx.RuleClass`
```

### 数据字典

```markdown
## 字典名称

**字典编码**：`DICT_CODE`

**说明**：字典用途说明

| 编码 | 名称 | 排序 | 状态 | 说明 |
|------|------|------|------|------|
| 01 | 名称1 | 1 | 启用 | 说明1 |
| 02 | 名称2 | 2 | 启用 | 说明2 |
| 03 | 名称3 | 3 | 停用 | 说明3 |
```
