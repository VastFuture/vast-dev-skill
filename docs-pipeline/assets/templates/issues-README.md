## 什么时候需要问题追踪

- 遇到 Bug 需要后续修复

## 问题报告模板

对于具体问题的详细分析，使用以下格式：

```markdown
# {问题标题}

> 发现日期：YYYY-MM-DD
> 最后更新：YYYY-MM-DD
> 状态：调查中 / 已确认 / 修复中 / 已解决

## 问题描述

（简要描述问题现象和影响）

## 复现步骤

1. ...
2. ...

## 根本原因

（如果已定位）

## 解决方案

（修复方案或临时 workaround）

## 验证结果

（如何验证问题已解决）
```
