# 产品需求文档：用户登录功能

> 创建日期：2026-06-01
> 状态：📝 草稿
> 负责人：张三

## 概述

**一句话描述**：为用户提供安全便捷的邮箱密码登录功能，支持会话保持和密码重置

**用户故事**：
作为网站访客，我想要通过邮箱和密码登录系统，以便访问我的个人账户和使用会员功能

## 背景与目标

### 背景

当前系统缺乏用户认证功能，无法区分访客和会员用户，也无法提供个性化服务。随着业务发展，需要建立完整的用户身份认证体系，为后续的用户画像、权限管理、个性化推荐等功能打好基础。

### 目标

1. **主要目标**：建立安全可靠的用户认证机制，支持邮箱密码登录
2. **次要目标**：提升用户体验，支持记住登录状态和快速密码重置

### 成功指标

- **登录成功率**：大于 95%（排除用户输入错误）
- **登录响应时间**：小于 500ms（P99）
- **用户留存**：登录功能上线后，7日留存率提升 15%

## 功能需求

### 核心功能

#### 功能点 1：邮箱密码登录

**描述**：用户输入已注册邮箱和对应密码完成身份认证

**用户流程**：
1. 用户访问登录页面
2. 输入邮箱地址和密码
3. 点击登录按钮
4. 系统验证凭据并跳转到用户首页

**验收标准**：
- [ ] 支持标准邮箱格式验证（RFC 5322）
- [ ] 密码长度至少 8 位，支持特殊字符
- [ ] 登录失败时显示清晰的错误提示
- [ ] 连续 5 次失败后锁定账户 30 分钟

#### 功能点 2：记住登录状态

**描述**：用户可选择保持登录状态，避免频繁重新登录

**用户流程**：
1. 在登录页面勾选"记住我"选项
2. 成功登录后系统生成长期有效的认证令牌
3. 用户关闭浏览器重新访问时仍保持登录状态

**验收标准**：
- [ ] 默认会话有效期 7 天
- [ ] 记住登录状态下有效期 30 天
- [ ] 支持主动退出登录
- [ ] 令牌泄露时支持强制失效

#### 功能点 3：忘记密码

**描述**：用户忘记密码时可通过邮箱重置

**用户流程**：
1. 点击"忘记密码"链接
2. 输入注册邮箱地址
3. 系统发送重置链接到邮箱
4. 用户点击链接设置新密码

**验收标准**：
- [ ] 重置链接 1 小时内有效
- [ ] 每个邮箱 24 小时内最多发送 3 次重置邮件
- [ ] 新密码必须与历史 3 次密码不同
- [ ] 重置成功后原有会话全部失效

### 非功能需求

- **性能**：登录接口响应时间 < 500ms，支持 1000 QPS
- **安全**：密码使用 bcrypt 加密，JWT 令牌包含用户基本信息
- **可用性**：登录页面支持键盘导航，兼容屏幕阅读器
- **兼容性**：支持 Chrome 90+、Safari 14+、Firefox 88+

## 技术方案

### 方案概述

采用前后端分离架构，后端提供 RESTful API，前端使用 React 构建登录界面。认证采用 JWT 令牌机制，会话数据存储在 Redis 中。

### 数据模型

```sql
-- 用户表
CREATE TABLE users (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  email VARCHAR(255) UNIQUE NOT NULL,
  password_hash VARCHAR(255) NOT NULL,
  salt VARCHAR(32) NOT NULL,
  failed_attempts INT DEFAULT 0,
  locked_until TIMESTAMP NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 会话表
CREATE TABLE user_sessions (
  session_id VARCHAR(128) PRIMARY KEY,
  user_id BIGINT NOT NULL,
  expires_at TIMESTAMP NOT NULL,
  is_remember BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id)
);
```

### API 设计

```http
POST /api/auth/login
Content-Type: application/json

{
  "email": "user@example.com",
  "password": "password123",
  "remember": true
}

Response:
{
  "success": true,
  "data": {
    "token": "jwt-token-string",
    "user": {
      "id": 12345,
      "email": "user@example.com"
    },
    "expires_in": 2592000
  }
}
```

### 前端设计

- 使用 React Hook Form 进行表单验证
- 密码输入框支持显示/隐藏切换
- 错误信息通过 Toast 组件展示
- 登录按钮在提交时显示加载状态
