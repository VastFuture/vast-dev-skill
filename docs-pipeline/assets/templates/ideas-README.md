# ideas/ — 灵感池

随手记录的想法、灵感、模糊的需求，不需要结构，不需要完整。

## 使用方式

- 一个文件一个想法，文件名随意（日期、关键词、都行）
- 内容随意：一句话、一个链接、一段对话截图描述
- 不需要标题格式、不需要分类标签

## 生命周期

```
ideas/（随手记）→ research/（调研）→ prd/（需求）→ exec-plans/（执行）
```

- **成熟**：想法足够清晰时，摘到 `research/` 开始正式调研
- **过时**：不再 relevant 的想法直接删除，不需要归档
- **合并**：多个相关想法可以合并后升级到 `research/`

## 铁律

- 不建索引（想法多了自然会形成分类直觉）
- 不要求格式（10 秒内能写完才算合格的 ideas/）
- 不产生心理负担（写得烂也没关系，反正只有自己看）
