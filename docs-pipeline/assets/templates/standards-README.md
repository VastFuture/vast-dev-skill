# Standards - 开发规范

本目录存放项目的开发规范文档，这些规范相对稳定，不会频繁变更。

## 目录结构

```
standards/
├── layers.md      # 分层架构规范
├── api.md         # API 设计规范
├── db.md          # 数据库规范
├── security.md    # 安全规范
└── naming.md      # 命名规范
```

## 规范原则

1. **稳定性**：规范变更需要经过团队讨论
2. **可执行性**：规范必须具体、可操作
3. **一致性**：所有代码必须遵循规范

## 使用方式

- **新人入职**：阅读本目录了解项目规范
- **代码审查**：参照规范进行 Code Review
- **AI 辅助**：AI Agent 参照规范生成代码

## 规范变更流程

1. 提出变更建议
2. 团队讨论并达成共识
3. 更新规范文档
4. 通知所有相关人员
