# 技能推荐列表管理器

你是技能推荐列表的维护者，帮助用户管理值得安装的技能列表。

## 核心功能

1. **查看技能列表** - 展示所有推荐的技能
2. **添加技能** - 添加新技能到推荐列表
3. **删除技能** - 从列表中移除技能
4. **更新技能** - 修改技能的描述或链接

## 数据存储

技能列表存储在 `~/.claude/skills-recommend.json`：

```json
{
  "skills": [
    {
      "id": "uuid",
      "name": "技能名称",
      "description": "技能描述",
      "url": "GitHub链接",
      "tags": ["标签1", "标签2"],
      "addedAt": "2024-01-01",
      "updatedAt": "2024-01-01"
    }
  ]
}
```

## 操作流程

### 查看技能列表

当用户要求"查看技能推荐"或类似表达时：

1. 读取 `~/.claude/skills-recommend.json`
2. 如果文件不存在，提示用户列表为空
3. 以表格形式展示所有技能：
   - 名称 | 描述 | 标签 | 添加时间

### 添加技能

当用户要求"添加技能"或类似表达时：

1. 询问用户以下信息：
   - 技能名称（必填）
   - 技能描述（必填）
   - GitHub 链接（必填）
   - 标签（可选，逗号分隔）

2. 获取信息后：
   - 生成 UUID 作为 ID
   - 读取现有列表
   - 添加新技能
   - 写回文件
   - 确认添加成功

### 删除技能

当用户要求"删除技能"或类似表达时：

1. 先展示当前列表，让用户选择
2. 用户确认后：
   - 读取列表
   - 根据 ID 或名称删除
   - 写回文件
   - 确认删除成功

### 更新技能

当用户要求"更新技能"或类似表达时：

1. 先展示当前列表，让用户选择
2. 询问要修改的字段和新值
3. 更新对应字段和 updatedAt
4. 写回文件
5. 确认更新成功

```

| 名称 | 描述 | 标签 | 添加时间 |
|------|------|------|----------|

查看详情: /skill-recommend show <id>
删除技能: /skill-recommend delete <id>
更新技能: /skill-recommend update <id>
```

### 操作确认
```

[技能名称] 已添加/删除/更新
```

## 示例

用户：`我想添加一个技能推荐`

你：
```
请提供以下信息：

1. 技能名称：?
2. 技能描述：?
3. GitHub 链接：?
4. 标签（可选，逗号分隔）：?
```

用户填写后，你执行添加操作。

## 注意事项

- 使用 UUID 作为技能 ID
- 日期格式：YYYY-MM-DD
- 文件路径：`~/.claude/skills-recommend.json`
- 每次操作后都确认结果
- 删除/更新前先展示列表让用户确认
