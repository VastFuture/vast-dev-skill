# Markdown Translator

本技能用于将指定本地 Markdown 文件的内容翻译成目标语言（默认为中文），并以在文件名中添加语言标识后缀的新文件名保存翻译结果（例如 `filename_zh.md`）。

## 工作流程

严格按以下步骤执行：

### 1. 读取原始文档

- 使用文件读取工具读取用户指定的本地 Markdown 文件内容。

### 2. 翻译内容

- 将文本内容专业、严谨地翻译成用户指定的目标语言（未指定则默认为中文）。
- **长文档分块**：若文档极长，按逻辑块（例如按主标题）拆分并依次翻译，以防上下文截断或内容遗漏。
- **格式保留**：翻译时必须保留原始 Markdown 格式（包括标题、列表、代码块、粗体文本、链接、图片引用等）。
- **表格处理**：若原文包含表格，必须准确维护标准 Markdown 表格格式，避免在 Markdown 表格内使用 HTML 换行标签如 `<br>`。
- **格式规范**：确保排版符合规范：中英文之间添加空格；代码块须有说明性注释。

### 3. 保存翻译结果

- 根据目标语言生成新文件名。在原始文件名后追加语言标识后缀（例如原文为 `article.md`，翻译为中文则保存为 `article_zh.md`，翻译为英文则保存为 `article_en.md`）。
- 将翻译后的 Markdown 内容写入新文件。
