# vast-skill-optimizer

技能优化工具 - 审查、规划并优化现有 Claude Code 技能。

## 来源

- **原始位置**: `~/.agents/skills/skill-optimizer/`
- **集成时间**: 2026-05-13
- **版本**: 本地版本

## 功能

- 技能结构审查
- 触发描述优化
- 工作流设计改进
- 确认门槛检查
- 渐进式披露优化

## 使用

```
/vast-skill-optimizer
```

## 工作流

1. **Scope** - 确定优化范围
2. **Review** - 审查目标技能
3. **Plan** - 输出优化计划并等待确认
4. **Implement** - 确认后实施
5. **Verify** - 校验结果

## 相关技能

- `vast-skill-forge` - 技能锻造工具
- `vast-skill-review` - 技能质量审查工具
