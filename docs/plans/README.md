# plans/

执行计划、任务拆解、变更记录

## 职责

- 存放功能开发的执行计划
- 记录任务拆解和依赖关系
- 归档已完成的计划

## 目录结构

```
plans/
├── completed/          # 已完成的计划归档
├── 2026-06-09-auth.md  # 带日期的计划文件
└── README.md
```

## 命名规范

- 活跃计划：`YYYY-MM-DD-功能名.md`
- 已完成计划：移动到 `completed/` 目录

## 计划模板

执行计划应包含：
1. 目标和范围
2. 任务拆解
3. 依赖关系
4. 时间估算
5. 验收标准
6. 状态记录
