# issues/

Bug 追踪、问题记录

## 职责

- 记录发现的 Bug
- 追踪问题状态
- 保存复盘分析

## 目录结构

```
issues/
├── 2026-06-09-auth-login-failed.md
├── 2026-06-10-db-connection-timeout.md
└── README.md
```

## 命名规范

- 格式：`YYYY-MM-DD-问题简述.md`
- 示例：`2026-06-09-auth-login-failed.md`

## 问题模板

每个问题应包含：
1. 问题描述
2. 复现步骤
3. 期望行为
4. 实际行为
5. 环境信息
6. 解决方案（修复后补充）
