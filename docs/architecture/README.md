# architecture/

技术基线、模块边界、分层规范

## 职责

- 存放技术架构文档
- 定义模块边界和依赖关系
- 记录分层规范和技术选型

## 文件内容

- 系统架构图
- 模块划分和边界
- 分层规范（如 adapter → application → domain ← infrastructure）
- 技术选型和约束
- 部署架构

## 与 design/ 的区别

| architecture/ | design/ |
|---------------|---------|
| 技术视角（怎么实现） | 业务视角（实现什么） |
| 模块边界、分层 | 功能设计、数据模型 |
| 跨切面关注点 | 单一功能关注点 |
