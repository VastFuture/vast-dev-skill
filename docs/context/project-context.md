## 真相优先级

当文档与代码冲突时，按以下优先级判断：

1. **代码实现**（最高）- 运行中的代码是最终真相
2. **测试用例** - 测试描述了代码的预期行为
3. **设计文档** - `design/` 中的设计意图
4. **需求文档** - `features/` 中的 PRD
5. **会议记录** - 历史决策参考
