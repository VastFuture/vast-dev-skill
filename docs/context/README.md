# context/ 目录说明

## 职责

存放项目的全局上下文信息，包括：
- 项目背景和目标
- 核心约束和假设
- 验证命令
- 真相优先级定义

## 文件说明

| 文件 | 说明 |
|------|------|
| `project-context.md` | 项目上下文模板 |

## 使用场景

- 新成员入职时，阅读 `project-context.md` 了解项目全貌
- 做决策时，参考上下文信息确保符合项目目标
- 写文档时，确保与项目背景一致

## 维护规则

1. 变更需经 Tech Lead 审核
2. 保持简洁，避免冗余
3. 定期审查，删除过时内容
