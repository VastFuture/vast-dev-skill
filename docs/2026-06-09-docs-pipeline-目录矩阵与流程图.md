## 二、目录分类矩阵

### 按生命周期分类

| 阶段 | 目录 | 用途 |
|------|------|------|
| **发现** | `docs/ideas/` | 灵感池 |
| **调研** | `docs/research/` | 技术选型、市场调研 |
| **定义** | `docs/prd/` | 产品需求文档 |
| **设计** | `docs/design/` | 设计意图 + 实现现状（SDD） |
| **规划** | `docs/exec-plans/` | 执行计划、任务拆解 |
| **规范** | `docs/standards/` | 开发规范、代码标准 |
| **追踪** | `docs/backlog/`, `docs/issues/` | 工作队列、Bug 追踪 |
| **复盘** | `docs/lessons/` | 经验教训 |
| **交接** | `docs/handover/` | 知识传递 |
| **上下文** | `docs/context/` | 项目上下文、验证命令 |
| **可视化** | `docs/diagrams/` | 架构图、流程图 |

### 按更新频率分类

| 频率 | 目录 |
|------|------|
| **高频** | `docs/backlog/`, `docs/issues/`, `docs/ideas/` |
| **中频** | `docs/prd/`, `docs/design/`, `docs/exec-plans/`, `docs/research/` |
| **低频** | `docs/standards/`, `docs/lessons/`, `docs/handover/`, `docs/context/`, `docs/diagrams/` |
