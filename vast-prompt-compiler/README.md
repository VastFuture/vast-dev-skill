# vast-prompt-compiler

Prompt 设计编译器 - 将用户原始需求编译为可指导 Prompt 写作的设计方案。

- **版本**: v1.0.0

## 功能

一个"知识对象路由器"和"Prompt 设计编译器"，通过 10 步流程：
1. 需求语义归一化
2. 问题原型识别
3. 学科/方法域路由
4. 能力缺口诊断
5. 候选知识对象召回
6. 知识对象验证与近邻辨析
7. 压缩价值反推
8. Prompt 注入映射
9. 后续 Prompt 设计指令
10. 轻量 Prompt 骨架

## 使用

```
/vast-prompt-compiler
```

## 触发词

- prompt 设计编译器
- compile prompt
- 设计 Prompt
- 需求编译

## 核心特点

- **按步骤执行**：每次只执行当前步骤，用户输入"继续"进入下一步
- **知识对象路由**：从哲学、心理学、社会学、管理学等学科路由高信息密度知识对象
- **验证与筛选**：每个候选对象必须经过既有性、稳定性、压缩性、可调用性、适配性验证
- **注入映射**：每个保留对象都必须说明进入未来 Prompt 的哪个位置
