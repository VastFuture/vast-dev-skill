## 简介

横纵分析法（Horizontal-Vertical Analysis）深度研究技能。由数字生命卡兹克提出，融合索绪尔的历时-共时分析、社会科学的纵向-横截面研究设计、商学院案例研究法与竞争战略分析的核心思想。

核心是双轴分析：
- **纵轴**：追踪从诞生到当下的完整生命历程（叙事故事呈现）
- **横轴**：在当下时间截面上与竞品/同类进行系统性横向对比

最终交叉两条轴产出独到洞察，生成排版精美的 PDF 研究报告。
