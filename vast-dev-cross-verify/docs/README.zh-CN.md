# MageByte Power Skills

**MageByte Power Skills** 是一个面向 Claude Code Superpowers 生态的领域专用工作流库，从真实生产事故中构建。其旗舰技能 `cross-verified-feature-development` 提供 7 阶段工作流，包含 4 轮独立 AI 验证。

## 核心创新：多视角验证

该工作流针对代码评审的一个根本缺陷：评审者与作者共享相同的假设，造成盲点。文档指出：

> "代码评审有结构性盲点：每个评审者都与作者共享相同的设计假设。"

解决方案使用 4 轮验证，评审者故意缺乏共享上下文，产生的 bug 集合接近**并集**而非重叠。

## 4 轮验证

| 轮次 | 焦点 | 典型产出 |
|------|-------|----------|
| 4.1 系统性自检 | 全上下文评审 | 1–3 bugs |
| 4.2 冷上下文评审 ⭐ | 仅代码，无设计文档 | **5–15 并发/幂等性 bugs** |
| 4.3 行为保留 Diff | 副作用对比 | 2–5 回归 |
| 4.4 跨仓库影响扫描 | 外部服务 | 0–3 影响点 |

**Phase 4.2 是最高价值步骤** — 它系统性地捕获标准评审遗漏的问题。

## 成本效益

| 指标 | 标准 | 本工作流 |
|------|------|----------|
| 额外时间 | — | +40–50% |
| Critical bug 检测 | ~40% | ~95% |

40% 更多时间换来检测率 55 点的提升。对于支付和核心状态机，值得。

## 平台支持

- **Claude Code**: 原生支持 via `~/.claude/skills/`
- **Codex CLI / OpenClaw**: 原生支持 via `~/.agents/skills/`
- **OpenCode**: 需要手动适配 agent 文件格式

## 何时使用

推荐用于：
- 💰 金融交易、支付、退款
- 🔄 订单/库存状态机
- 🔒 分布式锁、并发控制
- 🔗 跨服务契约
- 🗄️ Schema 迁移
- ⏱️ ≥3 人天且失败成本高的功能

工作流包含捆绑的参考文件，涵盖交叉验证技术、反模式、文档同步手册和电商领域案例研究。
